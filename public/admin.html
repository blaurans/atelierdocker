Administration

Cette page montre toute la classe — pseudos, progression, adresses IP — et permet de remettre un joueur à zéro. Le mot de passe est celui du fichier .env du serveur (ATELIER_ADMIN_KEY).

La session dure une journée de cours, puis le mot de passe est demandé à nouveau. Le mot de passe n'est jamais stocké dans le navigateur : il sert à obtenir un jeton, et c'est le jeton qui voyage.
